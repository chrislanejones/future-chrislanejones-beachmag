# Coastal ink sketches — November 2026

Created with the built-in image-generation tool, using the homepage's
`public/art/surfer-guy.webp` as the visual reference.

- `public/art/broken-surfboard.webp`: the 404 illustration, rendered as an alpha
  mask by `BeachFigure` so it uses the current theme's ink.

  “Elsewhere on the internet” links. `InkSketch` uses an inverted luminance mask

preserves the original standing character used as the reference for the seated
beach-chair version. The earlier transparency-edit experiment was not used.
